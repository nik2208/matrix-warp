# Application Source Code

This directory is the root placeholder for your project's implementation code.

When you create a new repository from this template:
1. Initialize your project stack inside this repository (e.g., Node/TypeScript, Python, Go, Rust, Flutter, etc.).
2. The autonomous pipeline in `.opencode/ci/runner.sh` and `.github/workflows/opencode.yml` will automatically detect, test, and implement features described in GitHub / Gitea / GitLab issues.
