# Security Policy / Politica di Sicurezza

## 🇬🇧 English

### Supported Versions
| Version | Supported |
| :--- | :--- |
| `1.x` | :white_check_mark: |
| `< 1.0` | :x: |

### Reporting a Vulnerability
If you discover a security vulnerability in **Matrix Warp**, please report it privately rather than opening a public issue:
1. Send a detailed report via GitHub Security Advisories (`https://github.com/nik2208/matrix-warp/security/advisories/new`) or email `lab@maribit.it`.
2. Include steps to reproduce or a proof-of-concept.
3. We will review the report within 48 business hours and release a fix as quickly as possible.

## 🇮🇹 Italiano

### Versioni Supportate
| Versione | Supportata |
| :--- | :--- |
| `1.x` | :white_check_mark: |
| `< 1.0` | :x: |

### Segnalazione di una Vulnerabilità
Se riscontri una vulnerabilità di sicurezza in **Matrix Warp**, ti chiediamo di segnalarla privatamente invece di aprire una issue pubblica:
1. Invia una segnalazione tramite GitHub Security Advisories (`https://github.com/nik2208/matrix-warp/security/advisories/new`) oppure via email a `lab@maribit.it`.
2. Descrivi la vulnerabilità allegando i passi per riprodurla.
3. Il team esaminerà la segnalazione entro 48 ore lavorative e rilascerà una patch correttiva il prima possibile.
