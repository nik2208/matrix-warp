# Security Policy

## Supported Versions

Le versioni supportate e manutenute ricevono aggiornamenti di sicurezza regolari.

| Versione | Supportata |
| :--- | :--- |
| `1.x` | :white_check_mark: |
| `< 1.0` | :x: |

## Reporting a Vulnerability

Se riscontri una vulnerabilità di sicurezza in questo progetto, ti chiediamo di segnalarla privatamente invece di aprire una issue pubblica:

1. Invia un'email dettagliata a `lab@maribit.it`.
2. Descrivi la vulnerabilità e, se possibile, fornisci passi riproducibili o un proof-of-concept.
3. Il team esaminerà la segnalazione entro 48 ore lavorative e rilascerà una patch correttiva il prima possibile.
